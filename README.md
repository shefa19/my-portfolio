## 📌 Overview

This is my personal developer portfolio — a fully responsive, accessible, and visually rich single-page website that showcases who I am, what I do, and the projects I've built.

It reflects my philosophy as a developer: **clean code, thoughtful design, and seamless user experiences.**

---

## 🚀 Key Features

- ✅ Fully responsive layout (mobile → tablet → desktop)
- ✅ Dark / Light theme toggle with system preference detection
- ✅ Custom animated preloader with progress bar
- ✅ Smooth scroll navigation + active section highlighting
- ✅ Scroll progress indicator
- ✅ Custom cursor (desktop only)
- ✅ Scroll-triggered reveal animations (staggered & scale)
- ✅ Interactive project cards with tilt effect
- ✅ Functional contact form powered by EmailJS
- ✅ Accessible (semantic HTML, ARIA labels, skip link)
- ✅ Optimized performance (lazy loading, preconnect, CSS variables)
- ✅ Background gradient orbs + grid effect
- ✅ Back to top button with smooth scroll

## 🔧 Setup & Installation

To run this project locally:

```bash
# 1. Clone the repository
git clone https://github.com/sishefa19/portfolio.git

# 2. Navigate to the project folder
cd portfolio

# 3. Open index.html in your browser
open index.html   # or double-click the file
```

> **No build tools or dependencies required.** This is pure HTML/CSS/JS.

## 📬 Contact Form Setup (EmailJS)

The contact form uses EmailJS to send messages directly to my inbox.

1. Create an account at [EmailJS](https://www.emailjs.com/)
2. Create a service (e.g., `portfolio_contact_form`)
3. Create a template (e.g., `template_54q6hun`)
4. Replace the `userID` in `js/script.js` with your public key:

```js
emailjs.init('YOUR_PUBLIC_KEY');
```

> ✅ Your current configuration is already set up — just verify the service & template IDs match.
